            Navigate the metric canvas
            
            
            
                World coordinates are metres. X runs right; Y runs up. Zoom
                changes the view, not the dimensions of the space.
            
            
            
            
                
            Create a circle
            
                
            
                    Choose Circle in the toolbar, or hold C and left-click. The
                    circle is centered under the pointer; its diameter matches
                    the current scale bar (10 m scale → 10 m diameter). Release
                    C to return to navigation. Circles keep their world-space
                    size.
                
            
                
            Brush (B)
            
                
            
                    Drag to draw a freehand stroke; release to finish. A click
                    makes a dot. Escape cancels an unfinished stroke. Width
                    starts at 3 screen pixels, then stays fixed in world metres.
                
            
                
            Path (P)
            
                
            
                    Click to place vertices. Move the pointer to preview the
                    next segment. Enter or Finish commits an open path. Click
                    within 10 pixels of the first vertex, or use Shift+Enter /
                    Close, to close a polygon outline after placing at least
                    three vertices. Backspace removes the last draft vertex;
                    Escape cancels. Polygons are outlines, not fills.
                
            
                
            Nodes (N)
            
                
            
                    In Node mode, click empty canvas to search for a node and
                    place it. Shift-click a node to toggle its selection. Drag
                    empty canvas by more than 4 CSS pixels to marquee-select
                    intersecting visible nodes. Drag a selected node body to
                    move the entire selection. Drag a selection-box corner to
                    scale uniformly by a positive factor about the opposite
                    corner; hold Alt when starting the drag to use the selection
                    center instead. Corner handles stay 8 CSS pixels wide at
                    every zoom. Only Node mode edits nodes. Drag between an
                    output on the right and an input on the left to create a
                    spline connection. You can also drag from input to output.
                    Each input accepts one connection; a valid new connection
                    replaces its old source. Outputs can feed multiple inputs.
                    Escape or Cancel cancels a gesture, restoring starting
                    positions and sizes for moves and scales. Focus loss,
                    pointer cancellation, or switching tools also cancels. The
                    Logic Board tab in Tools provides keyboard-operable node
                    selection, nudging, scaling, and port connection. Delete
                    nodes or the Delete key removes every selected node and its
                    attached connections in Node mode. Pan mode only navigates,
                    including when dragging over nodes.
                
            
                
            Visual graph prototype
            
                
            
                    The default node has integer ports A, B, and Result.
                    Connections do not execute anything. Self-connections and
                    mismatched port directions/types are rejected.
                
            
                
            Boards and Artboard layers
            
                
            
                    Artboard assets are behind Sketchboard strokes and shapes,
                    with Logic board nodes and networks in front. All boards
                    share one camera. Open the Artboard tab in Tools from any
                    canvas mode. The layer list runs front to back. Select a row,
                    double-click its name or use Frame selected to jump to it,
                    drag rows or use Raise/Lower to reorder, and Show/Hide or
                    Lock/Unlock each element. Locked elements allow canvas
                    clicks through and cannot be transformed, opacity-edited, or
                    deleted; they can still be selected in the list and framed.
                    Hidden elements are not rendered or picked.
                
            
                
            Images and SVGs (I)
            
                
            
                    Use Import or drop files on the canvas. Image mode selects
                    and moves images; drag corners to scale uniformly (Alt uses
                    the center) and the round handle to rotate (Shift snaps to
                    15°). The Artboard tab in Tools also provides keyboard
                    controls to select, nudge, scale, and rotate images. Escape
                    restores a gesture; Delete removes the selected image.
                    Reference URL loads a CORS-enabled HTTP/HTTPS image once.
                    Opacity helps with tracing. Artboard images sit behind
                    sketches and logic; SVGs remain in vector image context,
                    while raster images retain their source resolution. All
                    imports are in memory only.
                
            
                
            Pan (V)
            
                
            
                    In pan mode, drag with the left button. Middle-button drag
                    pans in any tool. With the canvas focused, arrows pan 40 CSS
                    pixels per step, or 200 with Shift. Hold WASD to pan
                    smoothly at 600 CSS pixels per second, or 3000 with Shift
                    (5×). Diagonal movement has the same total speed; opposing
                    keys cancel. Release to stop immediately. Focus loss, hiding
                    or leaving the page, Escape, beginning an edit gesture, or
                    Ctrl/Meta/Alt clears held movement. Hold Space to
                    temporarily pan with the left button, even over nodes;
                    release restores the selected tool and ends the pan drag.
                    Unfinished paths are preserved; active brush and node
                    gestures are canceled safely. Focus loss, hiding the page,
                    or opening help clears temporary pan. Repeated Space
                    keydowns do not toggle it. Editable fields and Ctrl, Meta,
                    or Alt shortcuts are left alone. Choose Pan for touch pinch
                    navigation.
                
            
                
            Zoom
            
                
            
                    Scroll around the pointer; use + / − around the view center.
                
            
                
            Trackpad
            
                
            Shift + scroll to pan; pinch to zoom.
            
                
            Touch
            
                
            Drag to pan; use two fingers to pan and pinch.
            
                
            Camera bookmarks
            
                
            Focus the canvas. Ctrl+1–9 saves a view; 1–9 recalls it.
                
            Origin
                
            
                    Press 0 or Home to reset the view to 100 pixels per metre.
                
            
            
            
            
            
                Circles, strokes, nodes, and connections are stored in memory
                for this page only. Switching tools discards unfinished drawing;
                committed objects remain. Reloading clears the scene. Strokes
                can be selected and deleted, but not moved; saved plans are not
                implemented.
